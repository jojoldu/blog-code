# API 가격은 제품 원가다

OpenAI가 GPT-5.6 Luna와 Terra의 API 가격을 각각 80%, 20% 인하했다.

100만 토큰 기준으로
Luna는 입력 $1 / 출력 $6에서 $0.20 / $1.20으로,
Terra는 $2.50 / $15에서 $2 / $12로 내려갔다.

표준 실시간 API 기준으로 Luna는 이제 Gemini 3.1 Flash Lite의 $0.25 / $1.50, GPT-4.1 mini의 $0.40 / $1.60보다도 저렴하다.

이것만 해도 놀라운데 현재 OpenRouter의 할인 모델 목록에는 Luna와 Terra가 여기서 다시 50% 할인된 가격으로 올라와 있다.

https://openrouter.ai/collections/discounted-models

그래서 OpenRouter를 통하면
Luna: $0.10 / $0.60
Terra: $1 / $6
이 된다.

프로모션 가격이라 언제든 바뀔 수는 있지만, 지금 가격만 놓고 보면 꽤 충격적이다.

가장 좋은 모델 하나만 골라서 모든 기능에 쓰면 편하다.
하지만 우리 같은 스타트업은 그렇게 할 수 없다.

현재 인프런에서는
Gemini 2.5 Flash Lite,
Gemini 3 Flash,
Gemini 3.1 Flash Lite,
Qwen 3.7 Plus,
GPT-4.1 mini,
Sonnet 5

등을 기능별로 나눠 API로 사용하고 있다.
각 기능에서 품질, 속도, 비용을 비교하고, 해당 영역에서 비용 대비 효과가 가장 좋은 모델을 사용한다.
(가난한 스타트업의 온몸 비틀기다 ㅠㅠ)

대신 여러 모델을 사용하더라도 서비스 코드가 모델마다 나뉘지 않도록 LLM Gateway를 구축해 두었다.
인터페이스는 하나로 통일하고, 뒤에서 사용하는 모델만 바꿀 수 있다.
그래서 모델을 교체하거나 일부 트래픽만 다른 모델로 보내는 것은 크게 어렵지 않다.

그렇다 하더라도 이번 가격은 Luna와 Terra 중심으로 확 통합해 볼 수 있겠다는 생각이 들게 했다.

물론 실제 기능에서 품질, 응답 속도, 안정성을 다시 확인해야 한다.
그래도 이 정도 가격 차이라면 검토하지 않는 쪽이 더 이상하다.

요즘 다들 코드 에이전트나 Cowork 같은 업무 에이전트와 기업 AX 이야기만 하지, API 가격 이야기는 잘 안 하는 것 같다.
하지만 AI를 사내 생산성 도구가 아니라 고객이 직접 사용하는 제품 기능으로 운영한다면 달라진다.
우리한테는 API 가격이 그대로 제품 원가다.

공교롭게도 DeepSeek는 조만간 API 가격을 크게 올릴 예정이라고 예고했다.
그래서 OpenAI의 이번 가격 인하와 OpenRouter의 할인이 격하게 반갑고 고마울 따름이다.

남의 회사 API 가격 인하 소식에 이렇게까지 반가워하고 있는 걸 보면, 요즘은 인프런을 교육회사라고만 설명하기가 조금씩 어려워지고 있다.
모델 단가를 비교하고, 게이트웨이를 만들고, 어떤 트래픽을 어떤 모델로 보낼지 고민하는 게 이제 우리가 풀어야 할 문제가 되었다.
